## Task 3: GitHub Profile Finder

### Objective
To use a public REST API and display fetched data dynamically on the webpage.

### API Used
GitHub Users API

Endpoint used:
https://api.github.com/users/{username}

Repositories endpoint:
https://api.github.com/users/{username}/repos?sort=updated&per_page=5

### Features
- Search GitHub profile by username
- Fetch and display profile details
- Show followers, following, and repositories
- Display recent repositories
- Loading state
- Error state
- Search functionality

### Technologies Used
HTML, CSS, JavaScript, Fetch API, GitHub REST API
