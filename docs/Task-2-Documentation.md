# Task 2: Study Planner / To-Do List App

## Objective
The objective of this task was to build a mini interactive JavaScript application using DOM manipulation.

## Project Description
This project is a Study Planner / To-Do List App that helps users add, manage, complete, edit, delete, search, and filter tasks.

## Features
- Add new tasks
- Select category
- Set priority
- Add due date
- Mark tasks as completed
- Edit tasks
- Delete tasks
- Search tasks
- Filter tasks by All, Pending, and Completed
- Clear completed tasks
- Clear all tasks
- Progress tracking
- Data saved using localStorage

## Technologies Used
- HTML
- CSS
- JavaScript
- DOM Manipulation
- localStorage
